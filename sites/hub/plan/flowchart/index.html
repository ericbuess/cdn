Text form. Node one: calibrate the instrument; if it sees the effect, go on; if not, one repair then stop; if the model is under the capability floor, every later null is "not at this scale". Node two: paper one, one number; below the bar, the generational pilot may be asked for and the harder tests run on paper one's checkpoints; above it, falsified at this scale and published, with the selection path still running from the other recipe; on the line, one replication and then the label "no detectable effect at this budget". Node three: the harder tests decide which path holds; they gate the powered study, not the pilot; a loss or a split is reported as such and no money is asked for the powered study. Node four: the generational pilot when funded; selection beating random opens the powered study; tracking random after three capped retries falsifies the selection path at this scale; a replicated divergence stop moves the detector paper up and blocks scale money. Node five: only a lab can take a held result further; a node is marked closed only when its failure has been shown at every size the programme reaches.

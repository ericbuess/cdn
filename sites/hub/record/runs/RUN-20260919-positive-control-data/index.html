RUN-20260919-positive-control-data.md

The data for the deliberative-style positive control (T0b, build plan section 2), built while the GPU was busy with the power slice.

  • Source scenes. dump_scenes.py replayed each of the twenty Jiminy Cricket training games' walkthroughs (jiminy-split-20260918.json, sha256 c4bf194e…) and, at every step, branched the walkthrough command plus verb-noun candidates from the saved state, keeping decision points where at least one candidate carried a non-zero annotation label: 2,004 decision points (pc-data/scenes-<game>.jsonl, hashes in pc-data/SHA256SUMS.txt).
  • Targets. make_pc_data.py: the walkthrough command when it carries no harm label, else the highest-reward candidate without one; four points skipped for want of a safe option; repeated (game, command) pairs capped at eight, which removed 261 (mostly runs of WAIT); 1,739 targets (pc-data/pc_targets.jsonl, sha256 0665f835…), each with up to eight shuffled options including up to three harm-labelled distractors.
  • Teacher. Gemini 3.8 Flash through Antigravity (teach_deliberations.py, batches of twenty-five), given the value specification v1 (VALUE_SPEC_v1.md, sha256 455bc2ae…) and the target letter, never a label; the first attempt returned nothing because the route tried to use tools in headless mode and was denied, so the prompt now forbids tools. Every deliberation that mentioned scoring, tests, labels, evaluation, benchmarks, rewards or points, or that ended on a different action, was dropped: 19 dropped, 1,720 kept (pc-data/pc_sft.jsonl, sha256 prefix 0ccd9df879e6df67). Coverage: all twenty games, 24 to 138 examples each; mean deliberation length 69 words; a second banned-word check on the kept file finds zero leaks.
  • Format. Chat form: a user turn (recent commands, the situation, the lettered options) and an assistant turn (three to five sentences of first-person reasoning from the principles, then Action: <letter>) <command>). The fine-tune script's dry run: 1,720 examples, mean 224 tokens, longest 460, none truncated at 1,024, 143,417 assistant tokens for the loss.
  • What it is and is not. Training data for an instrument check only. It is not the behaviour bank, not a target for any developmental or selection arm, and not evidence about the hypothesis. Eric may replace the specification's text before the control trains (a decision in the build plan's section 7); if he does, this file is regenerated and re-hashed.
  • Next. sft_positive_control.py --tag pc1 on the GPU after the T0a tail (about two epochs, effective batch eight, LoRA rank 16), then mach_eval_adapter.py with ADAPTER=out/pc-adapter-pc1 on the twenty power-slice games, read against the released model's rate: the bar is a ratio at or below 0.8.

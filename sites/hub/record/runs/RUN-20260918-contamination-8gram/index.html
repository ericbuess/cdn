RUN-20260918-contamination-8gram.md

What ran. contamination_check.py (this directory), CPU only, 31 seconds. For each of the 136 MACHIAVELLI games it takes every scene in game_data/scenarios/<game>_scenarios_bfs_filled.json, tokenises (lower case, punctuation stripped, split on whitespace), forms word 8-grams, and counts how many occur in the reference set built from all 25 Jiminy Cricket games (every double-quoted string literal in the game's .zil sources, the feelies text, the invisiclues and the walkthrough; 955,618 words, 481,137 distinct 8-grams). All 25 games are checked, a superset of any train split, so a train-only check can only report less overlap.

Rule (frozen in the proposal). A game is excluded from every split if more than 1% of its scenes' 8-grams appear in the Jiminy Cricket training games. The rule reads the occurrence fraction (8-grams of the scenes as played); the distinct-8-gram fraction is co-reported in the JSON.

Result. No game is excluded. The largest occurrence fraction is 0.032% (undercover-agent, 35 of 108,655 8-grams), then its-killing-time 0.031% and zombies 0.027%; the matches are stock phrases ("out of the corner of your eye you see", "that's for me to know and you to find out"). Every power-slice game is below 0.032%. Full table: contamination-8gram-20260918.json.

Four-part split. draw_split_four.py re-draws the split the proposal now describes (power slice, sealed 1a, sealed 1b, 1a-replication) from the same frozen shuffle as the three-part file of 2026-09-17 (random.Random(20260917).shuffle(sorted(games)), reproduced exactly), dropping excluded games (none) and cutting at positions 20, 68, 116: the power slice is unchanged (the 20 games already measured), sealed 1a 48 games, sealed 1b 48 games, 1a-replication 20 games (sized like the power slice; a proposed size, frozen before Phase 0). File: machiavelli-split-20260918-four-part.json, with its own sha256 and the recipe. The three-part file stays as history.

What this sets. The exclusion list (empty) and the four-part split file are build outputs the freeze table names as build tasks; the split sizes 20 / 48 / 48 / 20 are a proposed value until the Phase 0 block is frozen. No frozen threshold changes.

How to read these previews

  • Status chips distinguish built artifacts, prepared and proposed experiments, and missing outcomes; [confirm] marks facts still awaiting Eric's check.
  • The audio control on each page reads a short summary using the browser's own speech synthesis. It is synthesized speech, not a recording, and it reports an honest state where synthesis is unavailable.
  • Each page links to the project records its claims come from. Those records are private; opening them may require sign-in.
  • Keyboard: all navigation and controls are real links and buttons; Tab reaches everything.
